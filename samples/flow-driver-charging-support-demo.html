What this demo is showing

The key product idea is not just starting the charger. It is keeping the entire support journey inside Flow if something goes wrong.

1 • Scan Flow identifies the operator and charger

The driver does not need to work out which charging app or support channel belongs to the charger.

2 • Start The operator still provides the charging service

Flow presents the operator tariff and routes the charging request through the participating network integration.

3 • Problem Flow already knows what session failed

The app can carry the charger ID, operator, payment state, timestamps and session ID into the support flow.

4 • Support Chat or call without starting from zero

The driver can speak to Flow first. If required, Flow escalates the issue to the operator with the relevant session context.
